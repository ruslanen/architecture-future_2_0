# Аргументация этапов

1. Замена устаревших систем (Camel, MS SQL Server 2008)
- Устраняем технический долг.
- Снижаем риски простоя.
- Делаем базу для масштабирования.

2. Создание Lakehouse
- S3 + Trino дают дешёвое и гибкое хранение.
- Lakehouse объединяет гибкость Data Lake и удобство DWH.

3. Разделение по доменам (Data Mesh)
- Коанды сами отвечают за данные.
- Нет монолитного узкого горлышка.
- Быстрее подключаются новые компании.

4. Интеграция аналитики (Power BI, AI)
- BI и AI работают с "единой точкой правды"
- Повышается качество аналитики, меньше ошибок.

5. Усиление безопасности
- Выполнение законодательства (ФЗ-152).
- Снижение репутационных и юридических рисков.

6. Оптимизация и масштабирование
- Автоматизация ML pipeline сокращает time-to-market.
- Data Contracts обеспечивают стабильность обмена между доменами.
